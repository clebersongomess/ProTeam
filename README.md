# Sistema de Gestão de Projetos e Equipes

Projeto em Java com Spring Boot para gerenciar usuários, projetos, equipes e tarefas.

## Tecnologias
- Java 17+
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Spring Security (JWT)

## Como rodar
1. Configurar PostgreSQL com usuário e senha.
2. Atualizar application.properties com credenciais.
3. Executar `mvn spring-boot:run` ou rodar na IDE.
4. Endpoints disponíveis em `/api/usuarios`, `/api/projetos`, `/api/equipes`, etc.
