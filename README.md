# Sistema de Gestão de Projetos e Equipes

Projeto em Java com Spring Boot para gerenciar usuários, projetos, equipes e tarefas.

## Tecnologias
- Java 17+
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Spring Security (JWT)

## Como rodar
1. Bancos de dados utilizando o SupaBase na versão free.
2. Executar `mvn spring-boot:run` ou rodar na IDE.
3. Endpoints disponíveis em `/api/usuarios`, `/api/projetos`, `/api/equipes`, etc.
